# TaskFlow — JavaScript To-Do List

A responsive task manager built with HTML5, CSS3, and vanilla JavaScript.

## Features
- Create, read, update, and delete tasks (CRUD)
- Mark tasks as active or completed
- Filter tasks by All, Active, and Completed
- Automatically save tasks with `localStorage`
- Live summary counts
- Responsive layout for desktop, tablet, and mobile
- Accessible labels, keyboard focus states, and status announcements
- Dynamic DOM rendering and delegated event handling

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a browser.

Tasks are saved in the browser where you use the app. Clearing browser site data may remove saved tasks.
